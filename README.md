# MoleAssist

> 早年《摩尔庄园》第三方自动战斗辅助（当年的「鼹鼠辅助」）源码 —— **防御性安全研究存档**，仅供研究，不鼓励使用。

这是一份历史外挂工具的完整源码存档：一个 C# WinForms 上位机，通过 InlineHook 注入 + Lua 脚本驱动，自动化摩尔庄园回合制战斗玩法（自动出招、按顺序放技能、自动回血 / 用怒气、快速练级等）。收录它的目的是**理解当年淘米页游外挂的技术形态、留存失传的游戏史料、做安全科普警示**。

## 技术构成

| 模块 | 说明 |
|---|---|
| `MoleAssist/` | C# WinForms 主程序：战斗管理器 `FightManager`、配置管理、UI |
| `InlineHookLib/` | C++ 实现的 inline hook 注入库（`inlineHook.cpp`），挂钩目标进程 |
| `HookTest/` | inline hook 库的测试工程 |
| `Config/fight.lua` | Lua 战斗脚本，定义出招逻辑（技能顺序 / 回血 / 怒气 / 隐藏模式等选项） |
| `Lib/NLua.dll`、`KopiLua.dll` | Lua 运行时（在 .NET 中执行 `fight.lua`） |

脚本引擎（Lua）与注入层（InlineHook）分离，是这类自动化工具的典型架构：宿主负责挂钩与内存读写，Lua 脚本负责可热改的战斗策略。
